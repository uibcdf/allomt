# Research references

**Reviewed:** 2026-11-15. **Scope:** targeted scoping review for AlloMT design
round R02, covering established methods and developments through this date.

Primary papers and official software/model documentation support the analysis.
Searches covered rapid ENM/perturbation methods, networks/information theory,
energetic and mutational inference, generative ensembles and molecular design,
bitopic ligands, covalent discovery, and knowledge resources. Web search and
a connected scholarly search were used for discovery; claims below link to the
primary source. Some publisher full texts were inaccessible, so the review
uses indexed primary abstracts and accessible methods/documentation rather than
claiming a full-text systematic review. Search excerpts were not treated as
independent validation.

The date column distinguishes a resource's name from its publication date.
Preprints and software/model releases remain distinguished from peer-reviewed
papers. A paper's results apply to its studied systems, not to AlloMT or every
target class. No packages/models were installed or benchmarked in this review.

Repository licenses were read at immutable commits in
[the tool snapshot](research/tool_inventory_2026_11_15.json). Root code license,
weights, bundled assets, transitive requirements, service terms and scientific
validation are separate review questions. This snapshot is not an admitted
installation route.

See [methods/tools](METHODS_AND_TOOLS.md), [research trends](RESEARCH_LANDSCAPE.md),
[proposed extensions](PROPOSED_EXTENSIONS.md) and [the coverage audit](DESIGN_AUDIT.md).
